## What I’m building

### [OpenPlanr](https://openplanr.dev)

I used to plan coding-agent tasks by hand. OpenPlanr grew out of that habit.

Your agent writes the code. OpenPlanr is the open harness around it: plans as files in the repository, checks before you merge, and a record of what shipped. Claude Code, Codex, and Cursor build one task at a time against those plans.

The open-source toolkit includes 25+ skills for planning, implementation, verification, design, review, and operating decisions. The deterministic `openplanr` CLI checks the work offline and keeps GitHub Issues or Linear in step.

[Website](https://openplanr.dev) · [Source & docs](https://github.com/openplanr/OpenPlanr) · [npm](https://www.npmjs.com/package/openplanr) · [Course](https://openplanr.dev/learn/agentic-engineering) · MIT licensed

### [MentorSimply](https://mentorsimply.com)

I built MentorSimply so mentors can run paid sessions from one place: onboarding, bookings, payments, video, notes, and reviews.

I own the product and engineering, including role-based dashboards, in-platform WebRTC video, Stripe commissions and mentor payouts, referrals, and AI-assisted onboarding.
